# AGENT.md — <название проекта>

Мини-проект по определению сходимости расчётных значений параметров D и E тензора 
расщепления в нулевом поле с ростом активного пространства (CAS)
Тестовый запуск по материалам 10.1021/acs.jpca.4c00466

## Цель проекта
Ты должен по сырой таблицы из статьи, лежащей в папке `/data/` проекта в файле 
DMRG_table.csv посчитать параметры MAE, MAPE, rmsd и R^2 для 3-х величин 
|D|, |E| и |E/D|. Найди формулы для параметров в файле 
`data\statistic_formulas.md` проекта. Для расчёта напиши модуль на языке python. 
По окончании запиши результат в файл `diary.md`. Сформулируй способ проверки 
результата и опиши его в том же файле. 


## Данные и материалы
- `data/` — исходные данные: <что лежит, форматы, единицы измерения>.
- `paper/` — <статьи, черновики>.
- Исходные данные не изменять; производные файлы — в отдельных папках.
- `data/statistic_formulas.md` -- формулы для расчёта статистических параметров

## Как работать
- Код — в `src/`, запускать перед тем, как сообщать результат.
- Для работы напиши python-модуль для расчёта. 
- Каждый вывод сопровождается способом его проверки.
- Сводки и заметки для следующих сессий — в `memory/`.
- Перед работай с таблицей файл с табличными данными 
из csv с разделителем -- " " перевести в CSV с разделителем
";". Напиши скрипт для перевода. 
- Предложи способ проверки результата. 
- Запиши результат (4 параметра (MAE, MAPE, rmsd, r^2) для 3-х величин
(abs(D), abs(E), abs(E/D)) и способ проверки в `diary.md`

## Журнал
- После каждой задачи — запись в `diary.md`: дата, запрос, что сделано,
  результат, точка проверки, итог проверки. Старые записи не менять.
