# AGENTS.md — Парсинг и описание табличных данных из статьи

Проект по разработке агента для параметризации спектров время-разрешённой спектроскопии электронного парамагнитного резонанса

## 0. Цель и образ результата

Обработка спектров ЭПР-спектроскопии с временным разрешением (ВР ЭПР)

В конце работы в проекте существуют:
- `/results/spectra/slices` — каталог со срезами 2-х мерных спектров по оси магнитного поля в выбранные моменты времени 
- `/results/spectra/processed` — каталог со спектрами, очищенными от сигналов подложки, выбросов; к спектрам применены фильтры, которые не изменяют интерпретируемость
- `/src/ai4science_cleaning/` — скрипты, которые создал агент для обработки спектров в процессе работы

## 1. Критерий готовности

Работа считается выполненной, когда проходит проверка:

```
python "/mnt/c/Users/kurga/OneDrive/Документы/YSDA/AI4Science/my_project/checks/spectra_cleaned.py" "results/spectra"
```
Проверка возвращает 0, если в каталоге лежат дубликаты спетров из папки `data/raw_spectra` проведёной процедурой очистки, описанной в документации; в шапке файлов указаны использованные для очистки методы и их параметры

```
python "/mnt/c/Users/kurga/OneDrive/Документы/YSDA/AI4Science/my_project/checks/spectra_sliced.py" "results/spectra"
```
Проверка возвращает 0, если в каталоге лежат как минимум по одному срезу для каждого спектра из папки `/results/spectra/processed`; в шапке файлов продублированы детали обработки спектров для 2-х мерных спектров, к которой добавлены промежутки интегрирования, использованные при получении срезов 

Вызови проверку сам перед тем, как дать окончательный ответ. Ответ без пройденной проверки не принимается.

Проверь вручную, что количества спектров совпадают с условиями. Перечитай шапки полученных файлов

## 2. Карта проекта и источники

`/data/raw_spectra` — спектры для обработки. Только чтение
`/data/mars_doc` — документация библиотеки mars-epr
`/data/mars_examples` — примеры использования библиотеки mars-epr
`/src/mars_cleaning` — полезные скрипты для обработки спеткров, использующие функционал библиотеки mars-epr
`../.mars-epr` — среда uv с установленной библиотекой mars-epr. Перед работай активируй эту среду, используя команду `source ../.mars_env/bin/activate`
Агент не знает сам: 
	- Полезный сигнал начинается не от нуля. Нужно искать нарастающий по абсолютной интенсивности сигнал. 
		- Участки спектра до полезного сигнала можно усреднить и вычесть, чтобы убрать постоянный во времени шум

## 5. Протокол работы

Режим — конвейер с рассуждениями:
1. просмотреть скрипты в папке `/src/mars_cleaning` и их документацию
2. просмотреть файлы в папке `/data/raw_spectra`
3. выбрать методы и инструменты очистки
4. провести очистку спектров от постоянных шумов и явных выбросов
5. провести анализ необходимости и возможности применения фильтров
6. запустить фильтры, если возможно. 
7. сохранить результаты в папке `/results/spectra/processed`
7. найти максимумы по абсолютной интенсивности сигналов. Проинтегрировать их и сохранить в папке `/results/spectra/slices`
8. найти момент времени, когда форма сигнала перестаёт изменяться во времени. Если новая форма отличается от формы в максимуме и от шума, проинтегрировать, добавить результат в папку `/results/spectra/slices`
