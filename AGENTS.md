# AGENTS.md — Парсинг и описание табличных данных из статьи

Проект по извлечению результатов квантовохимических расчётов из статьи 10.1021/acs.jpca.4c00466 (лежит в `data\`). 
Получаем таблицы и методы расчётов. Рассчитываем статистики по таблицам. Делаем ревью результатов квантовой химии

## 0. Цель и образ результата

Парсинг таблиц из статьи и оценка метрик данных в них

В конце работы в проекте существуют:
- `\results\tables` — каталог с .csv файлами с табличными данными. Файлы названы по номеру таблицы (напр. Table_1); В шапке файла описаны методы расчёта, и те их детали, которые не указаны в названиях колонок таблицы; 
- `\results\tables\statistics.csv`
- `\src\zfs_stats.py` — скрипт для расчёта метрик.

## 1. Критерий готовности

Работа считается выполненной, когда проходит проверка:

```
python "C:\Users\kurga\OneDrive\Документы\YSDA\AI4Science\my_project\checks\check_tables.py" "results\tables"
```

Вызови проверку сам перед тем, как дать окончательный ответ. Ответ без
пройденной проверки не принимается.

Проверка возвращает 0, если в каталоге лежат файлы для всех таблиц статьи. Данные в файле Table_1.csv совпадают с данными
в таблице в каталоге `checks/`. Расчитанные статистики совпадают с указанными в таблице 1 в каталоге `checks/statistics.csv`



## 2. Карта проекта и источники

`\data\Paper.pdf` — статья для парсинга, только чтение. `\data\statistic_formulas.md` — формулы для требуемых метрик.
Агент не знает сам: с 7 страницы начинаются ссылки на литературу; описание расчётов в тексте статьи, искать рядом со ссылкой на индексируюмую статью;

## 3. Инструменты и границы

Чтение PDF, Python для пересчёта чисел из таблиц рукописи. Сети нет.

## 4. Запреты

1. Не изменять `Paper.pdf`. `[среда]` — права только на чтение.
2. Не менять `checks/` и ручной расчёт `checks/`. `[среда]` — папка вне рабочей копии агента.
3. Не выходить за пределы рабочей директории `[окно]`
4. Не читать содержимое папки `..\checks`\ `[окно]`


## 5. Протокол работы

Режим — конвейер с рассуждениями:
1. написать скрипт для расчёта метрик
2. по новой таблице в файле — один файл в `results\tables`;
3. адаптировать и запустить скрипт для расчёта метрик в новой таблице. Проверить вручную
4. поиск деталей расчётов, указанных в таблице, в тексте;
5 и далее. Повторить шаги 2-4 для следующий таблиц в тексте
