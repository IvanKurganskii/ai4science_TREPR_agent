## 1. Задача и место верификатора

Исследовательская задача — параметризация спектров
времяразрешённой ЭПР для донорно-акцепторных диад PBI–An. Из временно-полевых
измерений получают обработанные 2D-карты и временные 1D-срезы. Затем подбирают
параметры триплетной модели: g-фактор, параметры расщепления в нулевом поле D/E,
уширение и начальные населённости. Ошибка индексации, единиц или масштаба
может дать формально существующий, но физически бессодержательный результат.

Оцениваемый верификатор проверяет соответствие
сохранённого фита эксперименту и заявленным параметрам: масштаб,
происхождение данных, шумовой остаток, корреляцию, контрольное изменение D/E,
независимую локальную доводку и комплектность артефактов. Получение принятого
фита на данном этапе не заявляется: отрицательные вердикты и незавершённые
проверки включены в результат работы.


Предварительная обработка описывается для понимания
происхождения данных. Её вспомогательные проверки выявляли нулевые срезы,
но остаются ограниченными и не используются как основной верификатор ДЗ.
[написано]

## 2. Методика

Основная методика — [фитирование среза](../methods/fit_slice/METHOD.md);
[очистка и срезы](../methods/cleaning_slicing/METHOD.md) — дополнительный материал.

Метка:`exp-methods-v2`. Фит PBIAn1 от 08.11 выполнен раньше этой фиксации.
Сохранённые кандидаты проверены ретроспективно, без нового подбора.

Данные: четыре измерения PBIAn; для приведённых результатов
использованы PBIAn1_exp (241 точка, 9.70794454 GHz, 80.031 K) и
PBIAn2_exp2 (601 точка, 9.73843874 GHz, 79.963 K). Менялись g, D, E,
уширение и населённости; условия измерения фиксированы. В основной
проверке меняются только D′=−2D, E′=−E. Критерий: r≥0.32 и
Q_original≤Q_control, где Q=√(RSS/((N−p)σ²)), шум — до 500 ns.

## 3. Верификатор

Основная проверка — `check_fit_perturbation_1d.py`:
восстановление спектра из параметров, r≥0.32 и Q исходного не выше Q
контроля D′=−2D, E′=−E. Масштаб и остальные параметры фиксированы.

Комплектность: сохранённый спектр, сводная таблица
`1d-fit_results.csv` с одной строкой текущего фита и непустой SVG.
`check_fit_table.py` требует конечные параметры в рамках физически возможных для исследуемых систе:
D=100–10000 MHz,g=1–4, 0<lw_Gs<20 G.
а также соблюдения конвенций для неоднозначных параметризаци: 
E/D<1/3, , населённости в [0,1] с суммой 1±1e−6, 
Проверка не проводилась: сводная таблица отсутствует; отдельные CSV фитов есть.

Дополнительный независимый дофит —
`check_refit_1d.py`, MaRS Cobyla, до 500 вызовов и 300 s.
Требует установки среды

### Окружение

Нужен `uv`. Выберите одну опцию для создания среды Python 3.11 в `../.mars_env`.
Если среда уже подготовлена, перейдите к основной проверке.

**Вариант 1. Локальная копия MaRS с GitHub.** [Репозиторий MaRS](https://github.com/ArkadySamsonenkoWork/MaRs)

```bash
git clone https://github.com/ArkadySamsonenkoWork/MaRs.git ../MaRs
git -C ../MaRs checkout --detach fb8ce860b61d5d822c7eaf92f744c2ddf3262447
uv venv --python 3.11 ../.mars_env
uv pip install --python ../.mars_env/bin/python -e "../MaRs[opt]" \
  "numpy==2.4.6" "torch==2.14.1" "nevergrad==1.0.12" \
  "optuna==4.9.0" "optuna-integration==4.9.0" tqdm numdifftools hdbscan PyYAML
```

### Основная проверка
**Основная проверка Пирсона/Q:**

```bash
../.mars_env/bin/python checks_tmp_for_hw2/check_fit_perturbation_1d.py \
  --root "$PWD" \
  --slice results/spectra/slices/PBIAn1_exp_slice_max_7fa112cd9c81459eb36b403a510aae79.csv \
  --fit results/fits/1d/PBIAn1_exp_slice_max_2026-11-08/cobyla/cobyla_best_spectrum.npz \
  --fit-key intensity \
  --parameters results/hw2_report_2026-11-09/perturbation_saved_fits_20261109_024557/snapshots/PBIAn1_cobyla.json \
  --noise-window-ns 0 500 --n-parameters 6 --alignment none --min-pearson 0.32 \
  --report "results/hw2_report_2026-11-09/perturbation_$(date +%s%N).json"
```

Для запуска нужны срез, родительский 2D-спектр, NPZ
и полный JSON-снимок. Основная проверка использует MaRS для расчёта контроля. При повторе создаётся новый отчёт. Один запуск занимал
27–30 s. Дополнительный дофит `check_refit_1d.py` через MaRS опционален;
описание интерфейса — [REFIT_CHECKS.md](../src/utils/REFIT_CHECKS.md).
