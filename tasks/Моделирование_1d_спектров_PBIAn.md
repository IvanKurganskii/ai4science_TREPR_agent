# Моделирование 1d спектров PBIAn

Запрос пользователя: «Моделирование 1d спектров»

Готово, когда: для каждого из 4 processed спектров смоделированы минимум 2 среза (max intensity и late time); параметры спиновых гамильтонианов согласованы между срезами одного эксперимента; результаты сохранены в results/tables/1d-fit_results.csv
Не входит: моделирование 2d кинетик

## План
1. Срез PBIAn1_exp_slice_max — фит спиновых параметров
2. Срез PBIAn1_exp_slice_late — фит спиновых параметров (фиксированные из шага 1)
3. Срез PBIAn1_narrow_slice_max — фит спиновых параметров
4. Срез PBIAn1_narrow_slice_late — фит спиновых параметров (фиксированные из шага 3)
5. Срез PBIAn2_exp1_slice_max — фит спиновых параметров
6. Срез PBIAn2_exp1_slice_late — фит спиновых параметров (фиксированные из шага 5)
7. Срез PBIAn2_exp2_slice_max — фит спиновых параметров
8. Срез PBIAn2_exp2_slice_late — фит спиновых параметров (фиксированные из шага 7)
9. Агрегация результатов в results/tables/1d-fit_results.csv
