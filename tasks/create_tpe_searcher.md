# Создать скрипт TPE-поиска параметров среза ЭПР

Запрос пользователя: «Прочитай документацию и примеры для mars-epr. Создай папку /fit_utils и создай в ней скрипт для глобального поиска параметров среза (1d-спектра ЭПР) методом TPE»

Готово, когда: скрипт src/fit_utils/tpe_search.py создан, синтаксис проверен, базовые импорты mars-epr работают

Не входит: фитирование 2d-спектров, моделирование кинетики населённостей, создание заметок в графе

## Итог
Создан скрипт `src/fit_utils/tpe_search.py` (312 строк) для глобального поиска параметров 1d-спектра ЭПР методом TPE (Optuna TPESampler).

Скрипт:
- Принимает .npy/.npz файл с экспериментальным спектром
- Определяет параметрическое пространство: g-тензор (gx, gy, gz), ZFS (D, E), ham_strain, lorentz
- Запускает TPE-оптимизацию (500 trials по умолчанию)
- Сохраняет лучшие параметры в CSV и симуляцию в NPY

Синтаксическая проверка пройдена. Базовые импорты mars-epr проверены.
