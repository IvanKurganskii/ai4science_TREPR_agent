# Нормировка симулированного спектра под экспериментальный

Запрос пользователя: «Используя встроенный функционал mars напиши в src/utils модуль с нормировкой симулированного спектра под экспериментальный: С совпадающими максимумами, С совпадающим "размахом" -- расстоянием между максимумом и минимумом, С наименьшим среднеквадратичным отклонением одного от другого»

Готово, когда:
- Файл `src/utils/spectra_normalization.py` существует и импортируется
- Функция `normalize_sim_to_exp()` нормирует симуляцию под эксперимент: совпадение максимумов, совпадение размаха, минимизация RMS
- Функция `normalize_sim_to_exp_from_files()` работает по путям к CSV
- Функция `fit_linear_optimal()` — альтернатива через least-squares
- CLI-интерфейс: `python spectra_normalization.py sim.csv exp.csv [mars_mode]`
- Все тесты проходят: синтетические данные, разные сетки, CSV-файлы, режимы mars

Не входит:
- Интеграция в конвейер моделирования (следующий шаг)
- Работа с 2D-спектрами (только 1D-срез)

  * `normalize_sim_to_exp_from_files()` — то же по путям к CSV
