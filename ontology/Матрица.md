прямоугольный массив элементов с заданным порядком строк и столбцов

Отношения от этого класса: - хранитсяВ: Файл
- входитВ: ИнформационныйОбъект, Процесс
- содержит: ИнформационныйОбъект, Процесс
- представляет: ИнформационныйОбъект
- описывает: ИнформационныйОбъект, Процесс, ФизическоеЯвление
- характеризует: ИнформационныйОбъект, Процесс, ФизическоеЯвление
- соответствует: ИнформационныйОбъект
- заданДля: ИнформационныйОбъект
- удовлетворяет: МатематическоеСоотношение
- полученВ: Процесс
- вычисленИз: ИнформационныйОбъект.

Атрибуты: - базисПредставления: тип данных: string
- порядокБазисныхСостояний: тип данных: string
- порядокПараметров: тип данных: string.
