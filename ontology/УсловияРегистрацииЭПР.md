описание режима СВЧ, метода регистрации, модуляции, фаз, мощности и соглашений, необходимых для интерпретации конкретных данных ЭПР

- входитВ: ИнформационныйОбъект, Процесс
- содержит: ИнформационныйОбъект, Процесс
- описывает: ИнформационныйОбъект, Процесс, ФизическоеЯвление
- характеризует: ИнформационныйОбъект, Процесс, ФизическоеЯвление
- соответствует: ИнформационныйОбъект
- заданДля: ИнформационныйОбъект
- полученВ: Процесс
- вычисленИз: ИнформационныйОбъект.

Атрибуты: - режимСВЧ: значения: непрерывный, импульсный
- фазаСВЧРегистрации: тип данных: number; единица: deg
- фазаМодуляционнойРегистрации: тип данных: number; единица: deg
- калибровкаЗнака: тип данных: string
- мощностьСВЧ: тип данных: number; единица: mW
- насыщение: значения: пренебрежимо, существенно
