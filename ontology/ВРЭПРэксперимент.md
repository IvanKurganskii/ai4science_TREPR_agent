# ВРЭПРэксперимент

ЭПР-эксперимент, в котором регистрируют временную зависимость сигнала относительно заданного воздействия на образец

Отношения от этого класса: - решает: Задача
- проверяет: Гипотеза
- использует: НаборДанных
- применяет: Метод
- исследует: ФизическийОбъект
- сопровождается: Процесс
- даёт: Результат
- реализованВ: Файл
- входитВ: ИнформационныйОбъект, Процесс
- содержит: ИнформационныйОбъект, Процесс
- вход: ИнформационныйОбъект
- выход: ИнформационныйОбъект.

Атрибуты: - режимСВЧ: значения: непрерывный, импульсный
- типВозбуждения: значения: оптическое, микроволновое, электрическое, магнитное, ионизирующее, другое
- мощностьСВЧ: тип данных: number; единица: mW
- частотаСВЧ: тип данных: number; единица: GHz
- температура: тип данных: number; единица: K
- числоНакоплений: тип данных: integer
- временноеРазрешение: тип данных: number; единица: ns
- началоОтсчёта: тип данных: string
- длинаВолныВозбуждения: тип данных: number; единица: nm
- длительностьИмпульса: тип данных: number; единица: ns.
