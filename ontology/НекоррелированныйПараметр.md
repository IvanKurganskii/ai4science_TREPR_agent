# НекоррелированныйПараметр

параметр, имеющий нулевую ковариацию с указанным другим параметром при конечных вторых моментах в рассматриваемом распределении

Отношения от этого класса: - входитВ: ИнформационныйОбъект, Процесс
- содержит: ИнформационныйОбъект, Процесс
- описывает: ИнформационныйОбъект, Процесс, ФизическоеЯвление
- характеризует: ИнформационныйОбъект, Процесс, ФизическоеЯвление
- соответствует: ИнформационныйОбъект
- заданДля: ИнформационныйОбъект
- участвуетВ: СоотношениеПараметров
- полученВ: Процесс
- вычисленИз: ИнформационныйОбъект.

Атрибуты: - значение: тип данных: number
- нижняяГраница: тип данных: number
- верхняяГраница: тип данных: number.
