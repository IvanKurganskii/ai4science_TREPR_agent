# НормировкаСпектров_2026-10-30

Модуль `src/utils/spectra_normalization.py` — нормировка симулированного спектра под экспериментальный с использованием встроенного функционала mars-epr.

## Методы

### normalize_sim_to_exp()
Основной метод:
1. Интерполяция симуляции на сетку эксперимента (если различаются)
2. Базовая нормировка через `mars.spectra_processing.normalize_spectrum` (режимы: `max`, `integral`, `none`)
3. Линейная трансформация `y_norm = a·y_base + b`:
   - `a = range_exp / range_base` — совпадение размаха
   - `b = max_exp - a·max_base` — совпадение максимума
4. Опциональная обрезка за пределы диапазона эксперимента
5. Возврат нормированного спектра + диагностика (RMS, scale, offset, max/min)

### normalize_sim_to_exp_from_files()
Тот же алгоритм, но по путям к CSV-файлам.

### fit_linear_optimal()
Альтернатива: прямая least-squares подгонка `y_norm = a·y_sim + b` для минимизации RMS без ограничений на максимум/размах.

## CLI
```bash
python src/utils/spectra_normalization.py sim.csv exp.csv [max|integral|none]
```
