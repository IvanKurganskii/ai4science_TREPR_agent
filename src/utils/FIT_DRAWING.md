# Отрисовка и сэмплирование фитов

Рабочие команды и критерии — в [fit-drawing](../../instructions/fit-drawing.md).
Модули используют NumPy/Matplotlib; расчёт канонических полей дополнительно SciPy.
Все команды запускаются из корня проекта через `../.mars_env/bin/python`.
Модули не запускают оптимизацию и не меняют исходные спектры или результаты фита.

| Модуль | Назначение |
|---|---|
| `draw_fit_1d.py` | Один SVG с наложением фита среза и эксперимента |
| `canonical_orientations.py` | Шесть резонансных полей X/Y/Z из параметров, либо явно заданные поля |
| `sample_kinetics.py` | Извлечение экспериментальных и модельных кинетик на одинаковых полях |
| `draw_fit_2d_kinetics.py` | Функция `draw_kinetics(axes, sampled)` для шести кинетических панелей |
| `draw_fit_2d_slices.py` | `sample_slices(data, times_s)` и `draw_slices(axes, sampled)` для шести срезов |
| `draw_fit_2d.py` | Общий запуск: один SVG, 4 ряда × 3 столбца, шесть кинетик и шесть срезов |
| `fit_draw_io.py` | Общие загрузка, проверка осей, интерполяция, сохранение SVG |

## Формат входа

Поддерживаются штатные **NPZ фитеров**, `allow_pickle=False`. Нужны конечные
вещественные массивы и строго возрастающие оси, поле в T и время в s:

- 1D: `fields_T` (либо `field` в T), `intensity` (либо `spectrum`) и `experimental`.
  В экспортах TPE/COBYLA берётся **intensity**, уже приведённый к масштабу
  эксперимента; `simulated` — сырой расчёт и автоматически не выбирается.
- 2D: `fields_T`, `times_s`, `spectrum`, `experimental`, форма `(time, field)`.
  Модель и эксперимент должны лежать на одной сохранённой сетке. Если есть
  `experimental_times_s`, он задаёт ось записи, а `times_s` — ось модели;
  разность должна быть постоянной и совпадать с `metadata_json.time_zero_s`.
  Если сохранено только смещение, оно прибавляется к `times_s`; без обоих
  записей ось считается общей. Единицы/порядок из метаданных обязаны совпадать.
- `fit_mask`, если есть: булев непрерывный интервал минимум из двух времён.
  Графики используют этот интервал. Для старого файла без маски — вся карта.

И модель, и эксперимент должны быть ненулевыми. Неподдерживаемый экспорт сначала
явно преобразуй в новый согласованный NPZ; не подменяй оси и масштаб догадками.
`--spectrum-id` (синоним `--name`) — имя для `fitdraw_<spectrum_id>.svg`,
1–150 букв/цифр/`_`/`.`/`-`; `--fit-id` связывает рисунок с версией подбора.
`--output-dir` — существующий каталог этой версии. SVG открывается только как
новый файл. Для новой отрисовки используй новый каталог, сохраняя историю.

## Канонические поля

`canonical_orientations.py --parameters FILE` читает вертикальный CSV
`parameter,value,unit` или JSON штатного 1D-фитера, `spin_model`,
снимок `simulation.spin_model`, 2D-отчёт `fixed_spin_model`.
Нужны D/E/freq в **Hz**, g/g_iso — безразмерный скаляр или три главных значения.
В CSV единица D/E/freq должна быть `Hz`; сводная таблица `_MHz` сюда не подходит.

Для high-J S=1 решается условие резонанса соседних собственных уровней вдоль
трёх главных осей точного гамильтониана `H/h` из конвенции fit-slice/MaRS:
`(mu_B/h)*B*g_i*S_i + D*(Sz²-2/3) + E*(Sx²-Sy²)`.
Общий поворот согласованных g- и D/E-тензоров не меняет порошковые позиции.
Произвольные несовпадающие системы главных осей и модель moderate-J этим модулем
не рассчитываются. Размах энергий при B=0 должен быть меньше freq;
за пределами этой области явно задай нужные поля вместо выбора ветвей наугад.
Нужны freq > 0, g > 0 и |E| <= |D|/3. Более строгую конвенцию приёмки проверяй
отдельно; рисунок не исправляет параметры.

JSON содержит шесть `positions`: `label=X_left/.../Z_right`, `orientation`,
`field_T`, `levels` (номера собственных уровней с нуля). Список отсортирован
по полю; при вырождении сохраняются отдельные метки с совпадающими полями.
Ширины, ham_strain, населённости и a/e-паттерн не участвуют в расчёте номинальных
резонансных полей. Уширенные/перекрытые линии могут иметь другие экстремумы.
Необязательный `--report NEW.json` сохраняет этот компактный результат.

Альтернативы `--parameters`: `--fields-T B1 ...` либо
`--positions FILE.json`, где файл — список `{label, field_T}` или объект
`{"positions": [...]}`. 2D-рисунок требует ровно шесть полей с уникальными метками.
У отдельного сэмплера количество полей произвольное.

## Сэмплирование

По умолчанию применяется линейная интерполяция между соседними отсчётами.
`--field-half-width-T` задаёт полуширину окна и включает арифметическое среднее
измеренных точек в окне без весов; для срезов аналогично `--time-half-width-ns`.
Окно одинаково для обеих карт, полностью покрыто сеткой, содержит минимум один
отсчёт. Выход за область — ошибка; экстраполяции и привязки к ближайшему краю нет.
Отдельные кривые не нормируются. Настройки и использованные индексы сохраняются.

`sample_kinetics.py --fit FIT.npz --parameters PARAMS.json --output NEW.npz`
сохраняет `times_s`, `fields_T`, массивы `experimental`/`fitted` формы
`(time, position)` и `metadata_json` с происхождением и правилами сэмплирования.
В stdout только сводка и координаты, без массивов интенсивностей.

Для рисунка 2D обязательны `--times-ns t1 ... t6`, `--times-us` или `--times-s`:
шесть различных времён на оси записи, внутри окна сравнения. Все панели имеют
подписи полей/времён и легенду. Оси рисунка: mT и us, интенсивности сохранённого
фита. Для Python API `read_fit(path, "2d")` готовит общую карту,
`sample_kinetics(data, positions)` и `sample_slices(data, times_s)` извлекают пары.

## Контроль SVG

Проверки в общей папке checks независимы от кода проекта и используют стандартную
библиотеку Python. SVG содержит JSON происхождения и идентификаторы линий.
Проверяются имя/наличие, корректная SVG-разметка с положительным viewBox,
непустые видимые пути данных **обоих** рядов в каждой панели, нужные 1 либо 12
панелей, ненулевой сигнал по каждому семейству кривых, текущие IDs и SHA256 NPZ.
Пустые оси, только подписи, пропавшая кривая, шесть срезов без шести кинетик,
полностью нулевые отобранные кинетики и рисунок от прежнего NPZ не проходят.
Проверка ограничена SVG до 30 MB и не оценивает согласие модели с экспериментом.

У отрисовщиков/расчётчика коды: 0 — результат создан/рассчитан, 2 — ошибка.
У проверки: 0/`passed`, 1/`failed`, 2/`invalid`. Её JSON-отчёт обязателен и
сохраняется новым файлом внутри проекта. Команды — в AGENTS.md и fit-drawing.
