# Проверка Пирсона и контрольной модели D/E

Точки входа в `C:/Users/kurga/OneDrive/Документы/YSDA/checks/`:
`check_fit_perturbation_1d.py`, `check_fit_perturbation_2d.py`.
Общий модуль — `fit_perturbation.py`; он использует независимый адаптер MaRS
из `check_support/`, загрузчики `fit_noise.py` и снимок формата
[REFIT_CHECKS](REFIT_CHECKS.md). Код фиттеров проекта не импортируется.

## Порядок и критерии

1. Проверить данные, оси и происхождение среза; оценить шум после удаления
   линейного фона на подтверждённом предлазерном участке. Для 1D шум переносится
   из родительской 2D-карты с учётом операции получения среза.
2. Рассчитать знаковую корреляцию Пирсона между экспериментом и сохранённой
   моделью. Требуется **r >= 0.32**; модуль r не берётся. Для постоянного
   массива корреляция не определена — `invalid`. При r < 0.32 — `failed`,
   запуск MaRS для контроля пропускается.
3. Воспроизвести исходный спектр из снимка; относительное максимальное
   расхождение с сохранённой моделью не выше `--spectrum-rtol` (1e-5).
4. Рассчитать один контроль: **D'=-2D, E'=-E**. Всё остальное неизменно,
   включая g, уширения/ham_strain, числовые населённости, их базис и порядок,
   частоту, температуру, сетки, кинетические времена и рост сигнала.
5. Сравнить Q исходной модели и контроля на одном эксперименте и одном окне:

   `K = sum((experiment-model)^2) / ((N-p)*sigma_noise^2)`

   `Q = sqrt(K)`

   Требуется **Q_original <= Q_control**. Если контроль лучше, результат
   отклоняется. Равенство допустимо; фиксированный допуск машинного округления
   равен `64*eps(float64)*max(1,Q_original,Q_control)`. Это не практический
   допуск улучшения и не допуск контрольной Cobyla-доводки.

Исходная конвенция: D != 0, 0 <= E/D < 1/3. Контроль сохраняет её и уменьшает
E/D вдвое. E=0 допустим. Контроль может выйти за исходные границы подбора:
их не применяют к этому намеренному возмущению. Связи из снимка к контролю
повторно не применяются, чтобы сохранить все параметры, кроме D/E.

Масштаб и смещение калибровки фиксированы. При `normalization=maxabs`
делитель определяется только по исходной полной модели и применяется также
к контролю. Отдельная нормировка контроля, выравнивание амплитуды и повторный
фит запрещены. Для 2D сначала рассчитывается полная сохранённая временная
сетка; затем применяется окно сравнения. Пирсон 2D считается по всем точкам
этого окна после разворачивания карты в вектор.

## Запуск

Полные команды приведены в AGENTS.md, §1.3. Общие обязательные аргументы:
`--root`, `--slice` (1D) либо `--data` (2D), `--fit`, `--parameters`,
`--noise-window-ns START STOP`, `--n-parameters N`, `--report NEW_JSON`.
Выбери ключ NPZ модели в масштабе эксперимента через `--fit-key`: обычно
`intensity` для 1D, `spectrum` для новых 2D-фиттеров.

`--min-pearson` по умолчанию 0.32; в рабочих командах передавай его явно.
Порог фиксируется до подбора и меняется только по указанию пользователя.
`--alignment` допускает только `none`. Необязательный `--max-k` добавляет
отдельный абсолютный предел K; он не заменяет относительное сравнение Q.
Предел времени `--time-limit-seconds` — 300 s, включая импорт MaRS.

Опции происхождения среза и окон совпадают с [FIT_CHECKS](FIT_CHECKS.md):
`--source-2d`, `--slice-window-ns`, `--slice-operation`, `--integration-unit`,
`--slice-scale/offset`; для 2D — `--fit-window-ns`, `--fit-time-offset-ns`.
Их значения должны совпадать с основным контролем шума/доводкой.

Код 0/`passed` — оба этапа пройдены; 1/`failed` — нарушен критерий;
2/`invalid` или `inconclusive` — проверка не завершена успешно.
JSON включает исходные и контрольные r/Q/K/RMSE, D/E, делитель нормирования,
ошибку воспроизведения и SHA256 входов. Существующий отчёт не перезаписывается;
исходные спектры, параметры и таблицы не изменяются.

Проверка дополняет контроль шума, MaRS Cobyla, таблицы и SVG. Одно возмущение
не доказывает глобальный оптимум или единственность параметров. Пирсон зависит
от отношения сигнал/шум и не проверяет абсолютную амплитуду.
