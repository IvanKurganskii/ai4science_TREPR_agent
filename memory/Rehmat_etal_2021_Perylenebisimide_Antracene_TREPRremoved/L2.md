# L2 — тезисы

1. Ортогональная геометрия PBI-9-AN (торсионный угол 70.6–79.8°, центроидное расстояние 5.170–5.554 Å) обеспечивает квантовый выход образования триплетного состояния 86%, тогда как копланарный PBI-2-AN (угол ~54–55°) даёт 57% (с. 1, 3, 12).
2. Время разделения заряда (CS) составляет 1.48 пс для PBI-9-AN, 3.6 пс для PBI-2-AN и 9.2 пс для PBI-Bis-2-AN; рекомбинация (CR) протекает за 2.8 нс с популяцией триплетного состояния PBI (с. 7, 12).
3. Долгоживущее локализованное триплетное состояние PBI имеет время жизни τT = 139 мс в деаэрированном толуоле, которое увеличивается до 282.7–404.7 мс в плёнках PMMA за счёт подавления TTA-тушения (с. 1, 7).
4. ВР ЭПР-измерения проводились на X-band Bruker EMX (9.7 ГГц) с лазерным возбуждением Nd:YAG (532 нм) при концентрации образцов ~0.5 мМ в замороженном толуол/MeTHF (1:3) для определения механизма ISC по фазовому рисунку ESP (с. 7, 14).
5. Орбитали HOMO локализованы на антраценовом доноре, LUMO — на периленимидном акцепторе, что подтверждает направление переноса электрона от AN к PBI при фотовозбуждении (с. 9).
6. Донор AN окисляется при +0.93 В, акцептор PBI восстанавливается при −1.10/−1.32 В; термодинамическая разрешённость образования заряженно-разделённого состояния подтверждена при E00 = 2.40 eV и RCC = 4.58–6.53 Å (с. 5, 6).
7. Селективное возбуждение радикал-аниона PBI•− в ближней ИК-области (730 нм) не приводит к образованию дианиона PBI2−; формирование дианиона возможно только при возбуждении на λ < 522 нм (с. 11).
8. В спектрах поглощения наблюдается слабая LE-полоса PBI на 522 нм и сильная широкая CT-полоса на 610 нм; время жизни флуоресценции LE-состояния составляет 4.5 нс, CT-состояния — 9.0 нс (с. 4, 5).
